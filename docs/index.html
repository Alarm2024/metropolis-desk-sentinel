Run local demo

The agent itself runs on your machine. No keys and no network calls are needed:

git clone https://github.com/Alarm2024/metropolis-desk-sentinel.git
cd metropolis-desk-sentinel
./run.sh                      # UI at http://127.0.0.1:8080
./scripts/demo.sh             # one-shot deterministic demo, exits 0

To try the on-chain log without testnet, use a local Anvil chain (needs Foundry):

anvil --chain-id 10143 &
export PRIVATE_KEY=0x...      # paste one of the dev keys anvil prints
forge script script/Deploy.s.sol --rpc-url http://127.0.0.1:8545 --broadcast
RPC_URL=http://127.0.0.1:8545 ./scripts/record_card.sh hold_thin_liquidity
python3 -m http.server -d docs 8000
# open http://127.0.0.1:8000/?rpc=http://127.0.0.1:8545

This page also accepts ?address=0x… to read a different SentinelLog deployment.
